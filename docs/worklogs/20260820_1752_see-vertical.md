# Super Enhancement Engine vertical on Legend of Legaia

## Goal

Ship one end-to-end enhancement vertical on a real local title: hashed 2D
surface replacement, independently toggleable, pack-safe, software GPU
still the oracle.

## Done

- `enhance/see.c` — hash, orig/generated/user cache, unsharp+Scale2x,
  present composite, pack export (strips `orig.png`).
- GP0(A0) completion callback on `psx_gpu_t` (observer only).
- `armsx-qa --enhance --enhance-dir --serial`.
- `make test-see` — replacement on/off/user + pack export.
- `tests/boot_local.py --enhance --expect-diff`.

## Verified

Executed; output is real.

Cache key for that title is the *unenhanced* hash `1c859cc02ebe806e`
(orig.png + generated.png). Present output is `2f51fa06d28bb700`.

**Gate subset** `source cpu audio qa see` → exit 0, 7.740s.
Skipped `gpu chd zip sdl-audio` — host has no cmake/SDL2.

## Broken / Known issues

- `assets` counter in the QA done event only counts *new* orig dumps, so a
  second run prints `assets=0`. `enhance_applied` is the real flag.
- Path buffers in `see.c` trip `-Wformat-truncation` at PATH_MAX; not a
  functional bug at the lengths we use.
